# Sorkar Agro Care (সরকার এগ্রো কেয়ার) - Website Clone

A high-converting, fully responsive landing and checkout website clone of [sorkaragrocare.com](https://www.sorkaragrocare.com/) featuring:
- **Hotline & WhatsApp Number**: `01708-938787` / `+880 1708-938787`
- **Design & Layout**: Pixel-accurate clone built with modern Tailwind CSS and FontAwesome 6 icons.
- **Bangla Typography**: Google Fonts (`Hind Siliguri` & `Noto Sans Bengali`).
- **Floating Urgency Timer**: Persistent purple floating countdown bar with animated indicator and quick order button.
- **Hero Presentation**: Animated banner display with interactive slider controls and prominent call-to-actions.
- **Product Showcase**: Detailed cards for *Water Plankton Plus* & *Double Growth Plus* with benefits and features.
- **Interactive Checkout & Package Selector**:
  - 5 pre-configured pond size package tiers (10, 20, 30, 40, and 50 decimal options).
  - Real-time quantity increment/decrement controls (`+` / `-`).
  - Dynamic live recalculation of Subtotal, Delivery Charge (Free/৳0), and Grand Total.
  - Active card highlighting with checkmark badges.
- **Form Validation & Modals**:
  - Bangladeshi mobile number format validation.
  - Custom error popup with direct WhatsApp and Call quick-contact buttons.
  - Order success confirmation modal with instant order receipt and 1-click WhatsApp order copy dispatch to `01708-938787`.
- **Live Sales Popups**: Realistic real-time order notifications in the bottom corner.
- **Mobile Sticky Footer**: Persistent quick-action bar with Order, WhatsApp, and Call buttons for mobile users.
